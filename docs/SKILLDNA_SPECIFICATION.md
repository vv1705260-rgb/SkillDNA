# 1. Product Vision

SkillDNA is designed to create a continuously evolving digital representation of a person's real-world abilities.

Traditional professional profiles primarily depend on:

- Resumes
- Certificates
- Self-declared skills
- Course completion
- Static assessments

SkillDNA takes a different approach.

It focuses on **evidence of ability**.

The platform evaluates how a person performs practical tasks and uses measurable evidence to build a dynamic skill profile.
